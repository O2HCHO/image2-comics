漫画上色工作台 Image2 Comics 1.3

1. 将 ZIP 完整解压到任意本地文件夹，双击 Image2Comics.exe。
   不要从 ZIP 内直接运行；不要只复制 EXE，需保留 _internal 文件夹。
2. 打开“接口与上色设置”，填写 API URL、API Key 和模型。
   图像编辑地址示例：https://你的服务域名/v1/images/edits
   可测试连接获取模型，也可手动输入模型。
   API 会按服务商规则消耗额度，本应用不附带密钥或免费额度。
3. 默认提示词保留原稿线条、文字与分镜。可选多张已上色图片作为配色参考。
   参考图要求服务支持 image[] 多图编辑；不支持时请手动移除参考图。
4. 在“上色工作台”选择输入和输出目录，可包含子目录。
   列表默认全选，Ctrl / Shift 可多选，单击列表查看原图与结果。
5. 点击“开始 / 继续上色”。暂停、停止及关闭均等待当前请求完成并保存。
   成功且原图、参数和结果校验均未改变时，续跑会跳过。
   失败后可点击“重试失败项”。超时不会自动重发，避免重复计费。
6. 中断请求重启后显示“待确认”。服务可能已计费，确认后才手动重试。
7. 输出统一为 PNG，保留子目录，文件名带任务标识以避免覆盖其他结果。
   输出目录中的 .comic-color/tasks.json 为恢复清单，请与结果一起保留。
8. “整批监修 / 单页修改”按页序显示所有输入页的原稿和当前上色图。
   每组 8 页，滚动查看，使用“上一组 / 下一组”遍历全书。
   点击任意一页，在右侧修改该页完整提示词，再点“仅重新生成这一页”。
   从原稿整页重新上色；全局提示词不变，其他页不变。
   即使提示词相同也会新生成，成功后自动更新两处对照，失败则保留上一版。
   旧结果文件保留，当前采用版本在任务清单中记录，重启后恢复。
9. 点击“导出全部上色图为 PDF”，按输入目录的自然页序导出。
   每张输入页只导出当前采用的上色结果，不重复导出历史版本。
   有缺页时会先确认是否仅导出已有页；损坏或被修改的结果会提示修复。
   每张图独占一页，保持比例和像素，透明背景变白底。
   老版 colored_原文件名的结果会自动匹配，重名有歧义时不自动匹配。

设置和日志：%LOCALAPPDATA%\Image2Comics

文字保护（1.3）：
默认使用本地 CTD 字形分割和 YOLO 气泡检测，无需下载，无需 PyTorch。
只自动处理确认封闭的气泡和旁白框；框外、开放及不确定区域跳过。
先局部清除生成错字，再恢复原稿文字前景；不再贴回整矩形或整个气泡白底。
字形外扩、羽化默认各 1 像素，保留生成图底色；复杂底纹及边线粘连需核对。

已有结果可用“本地修复当前页文字 / 本地修复全部已有结果”，不调用生成 API。
“文字区域 / 掩码预览”显示蓝色气泡、绿色文字、橙色跳过候选；
可切换文字恢复与清字掩码，清字范围需先点击预览融合。
拖框人工补选可覆盖框外文字，仍按字形恢复；取消区域可排除自动结果。
明确没有可处理文字时使用零掩码；气泡内疑似漏字需核对或人工补选。
旧版缓存自动重检，原稿未变时保留人工补选、排除和参数。
只有旧融合图且缺少原始生成图时，无法可靠恢复旧白框底色，会提示核对。

文字融合会先对齐尺寸、裁切和轻微旋转；明显构图变化时拒绝自动贴回，
显示“文字需核对”，保留旧的当前结果及原始生成图。不要点击重新生成来
重做文字融合；请补选区域后使用本地修复，避免再次计费。
1.4.2 起最终上色图锁定原稿长宽比，不提供改变比例的补边选项。
请求附加原稿比例约束；服务返回比例偏差时，在保存前重新采样校正并严格校验。
无文字融合时保留接近生成图分辨率的合法整数尺寸；文字融合使用原稿画布尺寸。
旧的图片若已有补边或严重改画，仍可能无法对齐，需要核对；调整尺寸不能补回丢失的画面。
.comic-color/raw 保存原始生成图，text 保存检测和人工区域，masks 保存掩码。
这些文件与 tasks.json 需和输出图片一起保留；PDF 使用当前已采用的融合版本。
自动检测和对白筛选属于启发式，请目视抽查漏检、误检、错字残影及边缘接缝。

密钥仅在主动勾选“记住 API Key”后使用 Windows DPAPI 加密保存。
旧版设置只迁移非敏感项，首次使用请重新输入密钥。
预览仅加载当前页；大图的缩放预览最长边限制为 2400 像素，输出原图不受影响。
模型可能改变文字或人物细节，请抽查结果；参考图不保证所有页配色完全一致。
应用支持 PNG / JPG / JPEG / WebP / BMP，PDF 请先自行导出为图片。
Windows 10 / 11 64 位；无需安装 Python；联网和可用 API 服务为上色必需条件。

项目工作区（1.4.0）：启动首页 → 新建项目/接管旧漫画 → 选择工作区、原图与已有结果目录。项目不复制整批图片，旧结果不会自动融合。以后从最近项目打开即可恢复监修页和提示词；只需编辑当前页时，打开该页的文字区域。API 设置全局共用，编辑设置按项目保存。
